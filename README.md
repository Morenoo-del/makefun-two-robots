One funny line of awkward small talk that one robot says to another while they ride an elevator together.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/two-robots-out python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
